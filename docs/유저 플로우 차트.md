# V1 유저 플로우 차트

> Figma `10팀_Figma`의 V1 프레임에서 확인한 로그인, 취향 선택, 맵·정보·가이드·마이페이지 흐름을 기준으로 작성했다.

```mermaid
flowchart TD
    A[AUTH-01 로그인] --> B[카카오 OAuth 시작]
    B -->|취소·실패| C[로그인 실패 안내]
    C --> A
    B -->|성공| D[내 회원 정보 조회]
    D -->|비로그인·세션 만료| A
    D -->|ONBOARDING| E[PREF 취향 선택]
    E --> F[취향 전체 저장]
    F -->|ACTIVE 전환| G[메인]
    D -->|ACTIVE| G

    G --> M[1. 맵]
    G --> I[2. 정보]
    G --> H[3. 가이드]
    G --> P[4. 마이페이지]

    H --> H1[생성 조건 입력]
    H1 --> H2[생성 요청]
    H2 --> H3[생성 진행 상태 조회]
    H3 -->|완료| H4[가이드북 상세]
    H3 -->|실패| H5[오류 안내·재시도]
    H --> H6[내 가이드북 목록]
    H6 --> H4

    P --> P1[회원 설정]
    P --> P2[알림 목록]
    P --> P3[정책 안내]
    P --> P4[취향 수정]
    P --> P5[로그아웃]
    P --> P6[회원 탈퇴]
    P5 --> A
    P6 --> A
```

## 화면 공통 상태

- 최초 진입: 세션 확인 전 로딩 화면을 표시한다.
- API 진행: 중복 제출을 막고 진행 상태를 표시한다.
- 실패: 사용자가 이해할 문구와 가능한 경우 재시도 동작을 제공한다.
- 빈 결과: 오류와 구분되는 빈 상태 화면을 제공한다.

## 추후 구체화
